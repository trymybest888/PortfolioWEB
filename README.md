# OPIUM Portfolio

A four-page Thai portfolio inspired by underground fashion and editorial design.

- Introduction: app/page.tsx
- Skills: app/skills/page.tsx
- History: app/history/page.tsx
- Work: app/work/page.tsx
- Styling: app/globals.css

Replace YOUR NAME, the location, sample skills, history and concept projects with your own information. All sample content is labeled in the website. The hero illustration is AI generated.

Use npm install, then npm run dev for development. Use npm run build for the production build.
